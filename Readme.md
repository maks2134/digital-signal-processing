## Лаба 1 — свертка, корреляция, ДПФ (Wails + Go + React)

**Входные параметры сигнала (мат. модель):**
- **A** = [A0, A1, A2, ..., An] — амплитуды гармоник (массив)
- **f0** — базовая частота (Гц)
- **h** = [h0=1, h1, h2, ..., hn] — коэффициенты гармоник (h0 всегда = 1)
- **phi** — общая фаза (радианы)
- **duration** — длительность (секунды)
- **sample_rate** (например 44100 Гц)

**Формула сигнала:**
- **s(t) = Σ[i=0,n] Ai * sin(2π * hi * f0 * t + phi)**

Вариант реализован в `internal/dsp/service.go`:
- **x(t)**: A = [0.8, 0.5, 0.3], f0 = 330 Гц, h = [1, 2, 3], φx = 0
- **y(t)**: те же A, f0, h, но φy = π/2

### Структура проекта

- **cmd/lab1** — точка входа (`main.go`), здесь в реальном проекте настраивается Wails.
- **internal/app** — приложение и DTO для фронтенда, метод `Analyze()` для Wails.
- **internal/dsp** — уровень сервисов (DI), использует математическую библиотеку.
- **pkg/lab1** — математическое ядро (генерация сигналов, свертка, корреляция, DFT/IDFT).
- **frontend** — React + Vite + Chart.js для визуализации.

### Математическая часть (Go)

- **Генерация сигналов x(t), y(t)**: `pkg/lab1/signal.go` (`GenerateHarmonicSignal`).
- **Свертка**: `pkg/lab1/convcorr.go` (`Convolve`).
- **Корреляция**: `pkg/lab1/convcorr.go` (`Correlate`).
- **Прямое и обратное ДПФ** (реализация студента): `pkg/lab1/fft.go` (`DFT`, `IDFT`).
- **Заготовка под Open Source FFT**: комментарии в `fft.go` (можно подключить, например, `go-dsp/fft` и реализовать `FFTLib`, `IFFTLib`).

### Backend / Wails API

- **Сервис DSP**: `internal/dsp/service.go` — формирует x(t), y(t), свертку, корреляцию и спектры.
- **Приложение для Wails**: `internal/app/app.go` — метод `Analyze()` возвращает:
  - сигналы во временной области (x, y, conv, corr)
  - амплитудные и фазовые спектры (spectrumX, spectrumY, spectrumConv).
- **Точка входа**: `cmd/lab1/main.go` — сейчас содержит заглушку и инициализацию DI;
  для реального Wails-приложения нужно добавить импорт Wails и конфигурацию по документации.

### Frontend (React + Chart.js)

- В `frontend` создано Vite-приложение (React, TypeScript, Chart.js).
- `src/App.tsx`:
  - в реальном проекте вызывает Go-метод `Analyze()` через Wails (`wailsjs`),
  - строит графики:
    - x(t), y(t), свертка, корреляция во времени;
    - амплитудный и фазовый спектр для каждого сигнала.

### Как запустить (общая схема)

1. **Backend (Go / Wails)**:
   - установить Wails (по оф. документации),
   - в `cmd/lab1/main.go` добавить инициализацию Wails и привязку `app.App` как backend.
2. **Frontend**:
   - `cd lab1/frontend`
   - `npm install`
   - `npm run dev` (для разработки) или `npm run build` (для сборки).
3. Связать фронтенд и backend в конфиге Wails (путь к собранному `frontend/dist`).

Так выполняются требования методички: есть собственная реализация свертки, корреляции и ДПФ/ОПФ, а также заготовка под использование Open Source библиотеки для сравнения результатов и эффективности.
